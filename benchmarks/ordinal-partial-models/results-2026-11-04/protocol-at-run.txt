Dense nonparallel cumulative-link models: numerical confirmation
2026-11-04

This is implementation confirmation for an established model, not a study of
type-I error, interval coverage, or statistical novelty. The production baseline
is 45c0ff0. The candidate adds selected threshold-specific slopes while retaining
the original common-slope implementation when no columns are selected.

Fresh comparison block, fixed before run.R is executed:
For each logit, probit and cloglog link, generate two grouped designs using
seeds 115101 through 115106 in that order: 36 rows with 3 categories, 1 common
and 1 varying predictor; 90 rows with 5 categories, 2 common and 2 varying
predictors. Common predictors are standard normal; varying predictors are
uniform on [-1,1]. Thresholds span [-1.1,1.1], common slopes span [.25,.45], and
threshold-specific slopes follow .12*sin(threshold+predictor-1). Each row has
20 category observations, frequency weights cycle 1,2,0, and offsets are
sin(row)/10. The probability gaps
remain positive on this bounded varying-predictor domain. These inputs test
grouping, weights, offsets, dimensions and links; generated truth is used only
to produce the data and never enters either fitter.

Compare ML fits with ordinal::clm nominal effects, using the same integer
frequency likelihood, retained categories, predictors and offsets. Record both
fits' convergence, likelihoods, category probabilities and fastglm's remaining
score and predictor step. Numerical agreement criteria are absolute likelihood
error<2e-6 and maximum probability error<2e-6. These tolerances assess software
agreement, not scientific equivalence or inferential accuracy. Fastglm uses
inverse expected information; clm's covariance is not asserted to be identical.

For each fit, recode the first common predictor as 10+1000*x and the first varying
predictor as 2+5*z. Refit with the same model selection and check likelihood and
probability equivalence. This tests the target under an invertible affine
change of coordinates. Require probability error<2e-7. Invalid extrapolation,
nonconvergence and empty-category behavior are separate package regression
tests; no failed fit is silently replaced or omitted.

MASS housing, with Cont nonparallel and Infl/Type common, is an additional
external application comparison across all 3 links. It is an already inspected
development example and is labeled separately from the fresh block.

Run from the repository root after building the candidate:
  Rscript benchmarks/ordinal-partial-models/run.R OUTPUT_DIRECTORY

The output directory must not exist. The runner uses current source through
pkgload::load_all(compile=FALSE), saves inputs, all comparison records including
failures, full fits, session details and source/native hashes. The package's
runtime dependencies do not include ordinal; this developer comparator requires
ordinal and MASS. A subsequent implementation correction needs a new run
directory and an explicit account of the reused or fresh evidence.

Independent mean-bias-reduction validation, including generic expected-cumulant
checks and the author's original bpolr implementation, is kept separately in
benchmarks/partial-proportional-odds-validation. The earlier mathematical
prototype remains in benchmarks/partial-proportional-odds-design.
