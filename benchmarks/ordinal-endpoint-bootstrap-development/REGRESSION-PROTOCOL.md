# Ordinal regression bootstrap development study protocol

## Objective

Evaluate whether ordinal mean-bias-reduced (meanBR) percentile bootstrap
intervals may remain available when empty categories are limited to the two
endpoints. Keep the current public rule as the comparator. This is a
development simulation and will not by itself justify changing package
behavior.

## Data-generating design

The response follows a three-category proportional-odds logit model

\[
\Pr(Y_i \le j \mid x_i) = \operatorname{logit}^{-1}(\alpha_j - \beta x_i),
\quad j=1,2.
\]

The predictor is fixed and balanced, with 20, 40, or 80 observations at each
of `x = -1, 0, 1` for `n = 60, 120, 240`, respectively. The ordinal fit uses
the formula interface, a single linear predictor, fixed declared levels, and
meanBR. Parametric bootstrap keeps this design fixed.

| Scenario | Thresholds | Slope | Purpose |
|---|---:|---:|---|
| Rare lower endpoint | (-4.00, 1.20) | 0.50 | Endpoint-empty cases while the middle category remains common |
| Sparse interior | (-2.20, -2.05) | 0.30 | Negative control where middle-category absence changes the model |
| Moderate control | (-1.00, 1.00) | 0.50 | Baseline with all category probabilities away from zero |

Data are generated by inverse CDF from independent uniforms, conditional on
the fixed predictor. The outer simulation seed is `20261104`; dataset seeds
are deterministic functions of scenario, sample size, and replicate.

## Replication and bootstrap

There are 250 outer datasets per scenario and sample size (2,250 total). Each
converged meanBR fit with no empty interior category receives 199 parametric
bootstrap refits. A small two-dataset-per-cell timing pilot used a different
master seed (`20261103`) and is excluded from the main results. Datasets with
an empty interior category are retained in raw output but do not receive a
bootstrap, because their original fit has already collapsed the full
threshold model.

## Paired availability rules

Both rules use the same original fit and the same 199 refits:

1. **Current rule:** the original model and every refit have all declared
   categories represented; every refit converges and returns a finite
   coefficient vector.
2. **Endpoint allowance (candidate):** the original model and every refit
   retain the interior category; empty endpoints are allowed under meanBR;
   every refit converges and returns a finite coefficient vector.

No refit with an empty interior category is included in a candidate interval.
All failed datasets and refits remain in the raw output and contribute to the
reported availability and failure rates.

## Estimands and summaries

The targets are both generating thresholds and the common slope. Candidate
intervals are two-sided 95% percentile intervals using the same type-7 sample
quantiles returned by the package. For each parameter, coverage is reported
among datasets where the candidate interval is available, along with its
binomial Monte Carlo standard error. The interval availability rate is
reported separately; coverage conditional on availability must not be read as
unconditional performance. Also report the fraction of originals retaining
the interior category, endpoint-empty and interior-empty refit rates, and
nonconvergence rates. Joint threshold coverage is not a nominal target.

The expected standard error for coverage near 0.95 with 250 available outer
datasets is about 0.014. Sparse-interior cells may have few or no available
intervals; those cells are informative about the limits of the candidate rule
and will not be repaired by reducing the number of bootstrap refits.

## Scope and limitations

This study covers a single continuous predictor, three categories, a logit
link, and conditional parametric bootstrap. It does not cover pairs or cluster
bootstrap, other links, additional predictors, model misspecification, or
simultaneous confidence regions. No critical values, nominal levels, or
eligibility rules will be tuned to these results. A favorable result would
motivate broader validation and documentation, not an automatic change to the
public interface.
